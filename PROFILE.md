# Xelta - Create Images, Videos & More with Generative AI

Xelta AI Studio is a credit-based generative-AI content platform for creating images, videos, audio, micro-dramas, ads, and social content. It exposes an agent-native interface via a hosted MCP server and an llms.txt, but does not publish a conventional public REST/GraphQL API.

- **Provider:** https://xelta.ai

## APIs

- **Xelta MCP Server** — Hosted Model Context Protocol server exposing Xelta generation, workflows, marketing studio, analytics, workspaces, and automation tools. Connects via OAuth-style Xelta account sign-in; usable from Claude, Cursor, and ChatGPT. Consumption is tied to account credit balance. (`https://mcp.xelta.ai/mcp`)
